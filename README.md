# ITAcademy

Современный многостраничный сайт образовательного центра IT-направлений, созданный на HTML, CSS и vanilla JavaScript.

## Описание проекта

Сайт включает главную страницу, страницы курсов, преподавателей, расписания, поступления, контактов, FAQ, отзывов, проектов студентов и 404-страницу. Визуальный стиль сочетает dark academia, cyberpunk и современную технологическую эстетику.

## Структура проекта

- `index.html` — главная страница
- `about.html` — о центре
- `courses.html` — каталог курсов
- `course-details.html` — подробная информация о курсе
- `teachers.html` — преподаватели
- `teacher-details.html` — профиль преподавателя
- `schedule.html` — расписание занятий
- `admission.html` — запись на обучение
- `contacts.html` — контакты
- `faq.html` — часто задаваемые вопросы
- `student-projects.html` — проекты студентов
- `reviews.html` — отзывы выпускников
- `not-found.html` — 404
- `css/` — стили проекта
- `js/` — модули JavaScript
- `assets/` — подготовленная структура для изображений и иконок

## Используемые технологии

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Google Fonts
- Font Awesome

## Запуск проекта

1. Откройте папку проекта в браузере через локальный сервер.
2. Можно использовать простой статический сервер, например:

   python -m http.server 8000

3. Откройте в браузере:

   http://localhost:8000

## Функциональность

- адаптивная навигация
- фильтрация и поиск курсов
- валидация форм
- FAQ-аккордеон
- анимация появления секций
- счетчики статистики
- кнопка возврата наверх
- демонстрационный режим отправки форм без backend

## Замена демонстрационных данных

Все тексты, курсы, преподаватели, цены и отзывы находятся в HTML-файлах. При необходимости замените:
- названия программ и цены;
- описания преподавателей и их профили;
- отзывы и истории студентов;
- ссылки и контакты в шапке, футере и формах.

## Важное замечание

Так как в проекте отсутствует серверная часть, формы работают в демонстрационном режиме и отображают уведомление об успешной отправке, но не сохраняют данные на backend. Это сделано специально, чтобы можно было безопасно подключить API позднее.
